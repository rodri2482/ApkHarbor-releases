# ApkHarbor releases

Official public APK downloads for ApkHarbor. Source code remains in the private ApkHarbor repository.

[Download the latest release](https://github.com/rodri2482/ApkHarbor-releases/releases/latest)

The legacy [X86Go-releases](https://github.com/rodri2482/X86Go-releases/releases) update channel remains available for ApkHarbor 1.4.0 installations. Approved future updates are mirrored to both channels while those clients migrate. APKs require Android installation confirmation.

Only public release APKs and update metadata belong here. Never upload signing keys, credentials or private source.
