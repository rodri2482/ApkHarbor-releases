# ApkHarbor — Official Android App & APK Downloads

ApkHarbor is an Android game and app discovery catalog. Browse games and apps, read their details, save interesting posts, and open externally hosted download links. This is the official public repository for ApkHarbor APK releases, update metadata and brand assets.

## Discover games and apps with ApkHarbor

- Browse a poster-led catalog with game and app descriptions.
- Check versions, file sizes, developer information and compatibility details when supplied by the post author.
- Search loaded catalog entries and browse categories.
- Save posts, follow titles and view update information.
- Open a post's external download links or available mirrors.
- Read release notes and get ApkHarbor app updates through GitHub Releases.

Catalog entries link to files on external hosts. Game files are not stored in this repository. An ApkHarbor app update and a game download are separate downloads.

## Download and install ApkHarbor

1. Open the [latest official release](https://github.com/rodri2482/ApkHarbor-releases/releases/latest).
2. Under **Assets**, download the file named **ApkHarbor-<version>.apk**.
3. Open the APK on your Android device. If prompted, allow installation from the browser or file manager you are using, then confirm Android's installation prompt.
4. To update an existing ApkHarbor installation, install a newer APK with the same application ID and signing identity. Keep your current installation and data while updating.

The brand-kit ZIP and GitHub's automatically generated source archives are not Android installers. App updates always require Android's installation confirmation.

## Android compatibility

The current ApkHarbor releases target Android devices running Android 7.0 or newer. The APK includes ARM and x86 native variants; device compatibility and individual game requirements can differ. Check the notes for the version you download.

ApkHarbor's application ID is `com.apkharbor.app`. The app's source code is maintained privately; this public repository distributes releases and supporting public assets.

## X86Go is now ApkHarbor

ApkHarbor was previously named X86Go. This repository is the **only active official release channel**. The old `X86Go-releases` repository has been retired and archived.

Some older builds still check the retired update address. If your installed app cannot see a newer release, download the current APK here and install a compatible update manually. The original X86Go package and the ApkHarbor package are separate apps; follow the release notes when migrating.
