# ApkHarbor releases

Official public APK downloads for ApkHarbor. Source code remains in the private ApkHarbor repository.

**[Download the latest release](https://github.com/rodri2482/ApkHarbor-releases/releases/latest)**

This is the only active release channel. X86Go-releases was retired and archived on 2026-10-29; it will receive no new versions. Existing apps using its old address need one manually installed same-package/same-signing-key migration update that uses this channel.

Release 1.4.1 was copied here unchanged from the retired repository; the APK and update metadata hashes match. The proposed logo/brand-kit assets remain attached to release1.4.0 and are not yet bundled in those APKs.

Only public APKs, update metadata and approved brand assets belong here. Never upload signing keys, credentials or private source.
